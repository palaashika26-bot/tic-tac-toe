# 🎮 Tic Tac Toe

A clean, modern two-player Tic Tac Toe game built with vanilla HTML, CSS and JavaScript. Features a dark theme UI with smooth animations, winner detection, and draw condition handling.

---

## 🔗 Live Demo

**[Play Now → https://palaashika26-bot.github.io/tic-tac-toe/](https://palaashika26-bot.github.io/tic-tac-toe/)**

---

## ✨ Features

- 🟠 **Two player gameplay** — Player 1 is O, Player 2 is X
- 🏆 **Winner detection** — automatically detects all 8 win patterns
- 🤝 **Draw detection** — declares a draw when all 9 boxes are filled with no winner
- 🎨 **Color coded players** — O is orange, X is purple with glowing effects
- 💫 **Smooth animations** — stamp-in animation on every move
- 🌙 **Dark theme UI** — modern dark design with blurred overlay for results
- 🔁 **Reset & Play Again** — reset mid-game or start fresh after a result

---

## 🛠️ Built With

- **HTML5**
- **CSS3** — animations, CSS variables, backdrop-filter
- **JavaScript** — vanilla JS, no frameworks or libraries

## 🚀 How to Run Locally

1. Clone the repository
```bash
git clone https://github.com/palaashika26-bot/tic-tac-toe.git
```

2. Open the folder
```bash
cd tic-tac-toe
```

3. Open `index.html` in your browser — that's it, no setup needed!

---

## 🎯 How to Play

1. The game is for **2 players** on the same device
2. Player 1 clicks any box to place **O**
3. Player 2 clicks any box to place **X**
4. First player to get **3 in a row** (horizontally, vertically or diagonally) wins
5. If all 9 boxes are filled and no one wins, it's a **Draw**
6. Click **Play Again** to start a new game or **Reset** to clear mid-game
